# DXC Search — Docker Compose Runbook (Local & Prod)

This guide shows how to run the platform locally and in production using **base + override** Compose files.

## Prerequisites
- Docker Desktop (or Docker Engine) with Compose v2
- Free ports (defaults): **8081**, **5432**, **9000**, **9001**, **3000**
- For local: create `infrastructure/compose/local/.env.local` from the example

```bash
# Bash/Git Bash
cp infrastructure/compose/base/.env.example infrastructure/compose/local/.env.local
# Windows PowerShell
Copy-Item infrastructure/compose/base/.env.example infrastructure/compose/local/.env.local
# Windows CMD
copy infrastructure\compose\base\.env.example infrastructure\compose\local\.env.local
```

---

## 1) Start LOCAL environment

**One-line (all shells):**
```bash
docker compose -f infrastructure/compose/base/docker-compose.yml -f infrastructure/compose/local/docker-compose.local.yml --env-file infrastructure/compose/local/.env.local up -d --build
```

**Windows CMD (multi-line using ^):**
```cmd
docker compose ^
  -f infrastructure/compose/base/docker-compose.yml ^
  -f infrastructure/compose/local/docker-compose.local.yml ^
  --env-file infrastructure/compose/local/.env.local ^
  up -d --build
```

**Windows PowerShell (multi-line using backtick `):**
```powershell
docker compose `
  -f infrastructure/compose/base/docker-compose.yml `
  -f infrastructure/compose/local/docker-compose.local.yml `
  --env-file infrastructure/compose/local/.env.local `
  up -d --build
```

**Bash/Zsh (multi-line using \):**
```bash
docker compose \
  -f infrastructure/compose/base/docker-compose.yml \
  -f infrastructure/compose/local/docker-compose.local.yml \
  --env-file infrastructure/compose/local/.env.local \
  up -d --build
```

### Useful local URLs
- App: http://localhost:8081
- MinIO Console: http://localhost:9001  (login with `MINIO_ROOT_USER` / `MINIO_ROOT_PASSWORD`)
- Gotenberg health: http://localhost:3000/health
- Postgres: `localhost:5432` (use `PG_DB`, `PG_USER`, `PG_PASSWORD`)

> If your app doesn’t auto-create the bucket, create **pdf** in MinIO Console.

## 2) Manage LOCAL stack

**Status (ps)**
```bash
docker compose -f infrastructure/compose/base/docker-compose.yml -f infrastructure/compose/local/docker-compose.local.yml --env-file infrastructure/compose/local/.env.local ps
```

**Logs (all services)**
```bash
docker compose -f infrastructure/compose/base/docker-compose.yml -f infrastructure/compose/local/docker-compose.local.yml --env-file infrastructure/compose/local/.env.local logs -f
```

**Logs (specific service)**
```bash
docker compose -f infrastructure/compose/base/docker-compose.yml -f infrastructure/compose/local/docker-compose.local.yml --env-file infrastructure/compose/local/.env.local logs -f search-platform
```

**Rebuild app image & restart only the app**
```bash
docker compose -f infrastructure/compose/base/docker-compose.yml -f infrastructure/compose/local/docker-compose.local.yml --env-file infrastructure/compose/local/.env.local build search-platform
docker compose -f infrastructure/compose/base/docker-compose.yml -f infrastructure/compose/local/docker-compose.local.yml --env-file infrastructure/compose/local/.env.local up -d search-platform
```

**Stop (keep data)**
```bash
docker compose -f infrastructure/compose/base/docker-compose.yml -f infrastructure/compose/local/docker-compose.local.yml --env-file infrastructure/compose/local/.env.local down
```

**Stop & wipe volumes (delete Postgres/MinIO data)**
```bash
docker compose -f infrastructure/compose/base/docker-compose.yml -f infrastructure/compose/local/docker-compose.local.yml --env-file infrastructure/compose/local/.env.local down -v
```

## 3) Start PROD environment (override for production)

> Use a secure `.env.prod` (not committed). Typically generated by CI/CD or Ops.

**One-line:**
```bash
docker compose -f infrastructure/compose/base/docker-compose.yml -f infrastructure/compose/prod/docker-compose.prod.yml --env-file infrastructure/compose/prod/.env.prod up -d
```

**Windows CMD (multi-line):**
```cmd
docker compose ^
  -f infrastructure/compose/base/docker-compose.yml ^
  -f infrastructure/compose/prod/docker-compose.prod.yml ^
  --env-file infrastructure/compose/prod/.env.prod ^
  up -d
```

**PowerShell (multi-line):**
```powershell
docker compose `
  -f infrastructure/compose/base/docker-compose.yml `
  -f infrastructure/compose/prod/docker-compose.prod.yml `
  --env-file infrastructure/compose/prod/.env.prod `
  up -d
```

**Bash/Zsh (multi-line):**
```bash
docker compose \
  -f infrastructure/compose/base/docker-compose.yml \
  -f infrastructure/compose/prod/docker-compose.prod.yml \
  --env-file infrastructure/compose/prod/.env.prod \
  up -d
```

**Prod ps/logs/down** → use the same commands as local, but swap the `local` override/env with the `prod` ones.

## 4) Environment variables

**Local (`.env.local`):**
```ini
PG_DB=searchdb
PG_USER=search
PG_PASSWORD=searchpw

MINIO_ROOT_USER=miniominiouser
MINIO_ROOT_PASSWORD=miniominiosecret
MINIO_BUCKET=pdf

SPRING_PROFILES_ACTIVE=local
```

**Prod (`.env.prod`):**
```ini
PG_DB=CHANGE_ME
PG_USER=CHANGE_ME
PG_PASSWORD=CHANGE_ME_STRONG

MINIO_ROOT_USER=CHANGE_ME
MINIO_ROOT_PASSWORD=CHANGE_ME_STRONG
MINIO_BUCKET=pdf

SPRING_PROFILES_ACTIVE=prod
SEARCH_PLATFORM_IMAGE=ghcr.io/yourorg/dxc-search-platform:YOUR_TAG
```

> ⚠️ Never commit real secrets. Keep `.env.local` and `.env.prod` gitignored or generate them from your secret store.

## 5) Notes & Troubleshooting

- **Ports in use** → adjust mappings in `local/docker-compose.local.yml`.
- **MinIO auth fails** → ensure credentials match your env file; use `down -v` to reset if needed.
- **Gotenberg errors (415/422)** → ensure you POST `multipart/form-data` with `files` named `index.html`.
- **Slow first build** → Maven dependencies are cached after the initial build.
- **Bind mounts** are for local only. Avoid in prod; pin images and enable restart policies & log rotation.
- **Spring profiles**: `SPRING_PROFILES_ACTIVE` is already set via env; local uses service names (`postgres`, `minio`, `gotenberg`) on the internal network.
