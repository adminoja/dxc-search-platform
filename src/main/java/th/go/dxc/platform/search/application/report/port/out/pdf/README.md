# PDF Port

This folder contains interfaces and implementations for generating and exporting PDF reports within the DXC Search Platform application.

## Structure

- **Interfaces**: Define contracts for PDF generation and export.
- **Implementations**: Provide concrete logic for PDF handling.

## Usage

Import and use the provided interfaces to integrate PDF report functionality in your application modules.

## Related

- See parent directories for additional report export options (e.g., Excel, CSV).
